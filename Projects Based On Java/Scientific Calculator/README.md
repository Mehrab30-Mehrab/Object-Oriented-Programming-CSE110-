## 🚀 About The Project

The Scientific Calculator System is a console-based Java application that performs basic and advanced mathematical operations.  
It features a colorful ANSI-styled interface, dynamic date & time display, and session-based operation counting.

This project was developed as part of the CSE110 coursework to demonstrate understanding of Java fundamentals and mathematical computations.

---

## ✨ Features

✅ Addition (Multiple Numbers)  
✅ Subtraction  
✅ Multiplication (Multiple Numbers)  
✅ Division (With Error Handling)  
✅ Power Function (x^y)  
✅ Square Root  
✅ Trigonometric Functions (Sin, Cos, Tan)  
✅ Logarithm (Base 10 & Natural Log)  
✅ Exponential (e^x)  
✅ Factorial  
✅ Operation Counter  
✅ Dynamic Date & Time  
✅ ANSI Colored Console UI

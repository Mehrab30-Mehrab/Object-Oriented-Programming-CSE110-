## 🎲 Project Overview

The **Dice Roller Program** is a Java console application that simulates rolling one or more dice.

Users enter how many dice they want to roll, and the program:

- Generates random numbers (1–6)
- Displays ASCII-art dice faces
- Calculates the total sum
- Validates user input
- Uses defensive programming with default cases

---

## ✨ Features

✔ Random dice rolling using `Random` class  
✔ ASCII visual representation of dice faces  
✔ Total score calculation  
✔ Input validation using `hasNextInt()`  
✔ Default case in switch for safety  
✔ Clean console-based UI

## 🧠 Program Flow

1. User enters number of dice
2. Program validates input
3. Random numbers between 1–6 are generated
4. ASCII dice faces are printed
5. Total score is calculated
6. Program exits safely

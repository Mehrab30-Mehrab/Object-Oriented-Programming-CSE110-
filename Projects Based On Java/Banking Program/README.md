## 🚀 About The Project

The **Banking Program** is a Java console-based application that simulates real-world banking operations.

It allows users to:

- 💰 Check Balance  
- ➕ Deposit Money  
- ➖ Withdraw Money  
- 🚪 Exit Securely  

This project demonstrates strong understanding of:

- Loops
- Methods
- Switch Expressions (Arrow Syntax)
- Scanner Class
- Variable Scope
- Conditional Logic
- Input Validation

---

## ✨ Features

✔ Interactive menu-driven system  
✔ Continuous execution using `while` loop  
✔ Secure transaction validation  
✔ Prevents negative deposits & withdrawals  
✔ Protects against insufficient funds  
✔ Clean formatted currency display

## 🧠 Program Flow

1. Program starts with balance = 0  
2. Menu is displayed  
3. User selects option (1–4)  
4. Based on selection:
   - 1 → Show Balance  
   - 2 → Deposit  
   - 3 → Withdraw  
   - 4 → Exit  
5. Loop continues until exit
